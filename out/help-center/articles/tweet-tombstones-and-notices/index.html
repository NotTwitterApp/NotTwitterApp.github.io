About Tweet tombstones and post notices

Updated May 24, 2026

A tombstone is the gray notice box Not Twitter renders in place of a post when the frontend has enough information to show why the post is hidden, limited, or unavailable. These visuals are live dummy tombstones, not screenshots.

Common tombstones

Limited visibility

You’re unable to view this Tweet because this account owner limits who can view their Tweets. Learn more

Sensitive post notice

This Tweet may include sensitive content.

Sensitive media with a View action

The following media includes potentially sensitive content.

Change settings

A post you reported

You reported this Tweet.

Muted account

This Tweet is from an account you muted.

Muted word

This Tweet includes a word you muted.

Unavailable or enforced posts

Rules violation

This Tweet violated the Bluesky Community Guidelines. Learn more

Suspended account

This Tweet is from a suspended account. Learn more

Withheld in a country

This Tweet from @example.com has been withheld in Germany based on local law(s). Learn more

Account no longer exists

This Tweet is from an account that no longer exists. Learn more

Unavailable post

This Tweet is unavailable. Learn more

Age restricted

Age-restricted adult content. This content might not be appropriate for people under 18 years old. Learn more

What the buttons do

  • Learn more opens this article when the notice is a frontend explanation.
  • Change settings opens Not Twitter settings because that control is local to this frontend surface.
  • View appears only on tombstones that can be temporarily expanded in the current screen.

Where Bluesky policy starts

Bluesky moderation, reporting, account status, labels, and policy enforcement are Bluesky topics. For those, use Bluesky moderation help and the Bluesky Community Guidelines.
